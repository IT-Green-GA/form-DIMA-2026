### 5.2 Tabla `registros`

Creada mediante una migración del MCP (`crear_tabla_registros`):

```sql
create table public.registros (
  id            bigint generated by default as identity primary key,
  fecha         date        not null,
  parcela       text        not null,
  cultivo       text        not null,
  actividad     text        not null,
  observaciones text,
  creado        timestamptz not null default now()
);

alter table public.registros enable row level security;

create policy "lectura publica"   on public.registros for select using (true);
create policy "insercion publica" on public.registros for insert with check (true);
```

- **RLS:** activado, con dos políticas (lectura e inserción). Sin ellas la aplicación no podría leer ni guardar.
- **Advisors de seguridad de Supabase:** sin observaciones (`lints: []`).

## 6. MCP de Supabase en OpenCode

Configuración escrita en el archivo global de OpenCode V2:

**`C:\Users\moyic\.config\opencode\opencode.json`**

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "supabase": {
        "type": "remote",
        "url": "https://mcp.supabase.com/mcp"

    }
  }
}
```

Autenticación realizada desde la interfaz de OpenCode con el comando **`/mcps`** (flujo OAuth en el navegador). Estado: **conectado**.

## 7. Problemas encontrados y soluciones

| Problema | Causa | Solución |
|---|---|---|
| `node`/`npm`/`pnpm` no reconocidos en la terminal | Node.js ya estaba instalado pero la sesión no tenía el PATH actualizado | Se usó la ruta directa; en una terminal nueva funciona sin más |
| `winget install OpenJS.NodeJS.LTS` falló (código 1603) | Ya existía una versión más reciente de Node.js instalada | No era necesario reinstalar |
| `corepack enable pnpm` falló (`EPERM`) | Requiere permisos de administrador en `C:\Program Files\nodejs` | Se instaló con `npm install -g pnpm@11.5.0` (carpeta del usuario) |
| `.env.local` vacío (0 bytes) | El archivo se creó pero no se había guardado | Se guardó de nuevo |
| La app no conectaba (`supabaseUrl is required`) | Las variables tenían nombres de **Next.js** (`NEXT_PUBLIC_*`) en lugar de los de **Vite** | Renombradas a `SUPABASE_URL` y `SUPABASE_PUBLISHABLE_KEY` |
| `.env.local` no estaba en `.gitignore` | El repositorio solo ignoraba `.env` | Se agregó `.env.local` y `.env.*.local` |
| La lista y el guardado fallaban con **404** (`PGRST205`) | La tabla `registros` no existía en Supabase | Se creó con el MCP de Supabase |
| `opencode mcp list` fallaba (`Database is not empty...`) | El comando `opencode` del PATH era **v1.19.3**, incompatible con la app **v2.0.32** | Se usó el CLI incluido en la app de escritorio (`...@opencodedesktop\resources\opencode-cli.exe`) |
